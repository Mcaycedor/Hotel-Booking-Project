# @gen/infra-components

AWS CDK constructs for the PF GEN Platform infrastructure.

## Installation

Ensure your local `.npmrc` is configured to point `@gen` to GitHub Packages.

```bash
pnpm install @gen/infra-components
```

## Documentation

Refer to the root project README for setup instructions.

For a complete example of how to use these constructs, please refer to the starter infrastructure application in this repository:
