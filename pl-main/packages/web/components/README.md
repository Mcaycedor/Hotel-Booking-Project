# @gen/ui-components

Angular UI package for the GEN Platform.

## Components

| Component  | Selector           | Description                                              |
| ---------- | ------------------ | -------------------------------------------------------- |
| `HomePage` | `gen-home-page`    | Home page layout with hero banner and content projection |

## Installation

Ensure your local `.npmrc` is configured to point `@gen` to GitHub Packages.

```bash
pnpm install @gen/ui-components
```

## Documentation

Refer to the root project README for setup instructions.
