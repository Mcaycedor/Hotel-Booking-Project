🗂️Phase 1: Data Collection & Storage

User uploads resume and job description

Resume Storage: Text → stored in resumeText property

Job Description Storage: Text → stored in jobDescription property

Extracted Data Objects Created Automatically:
  • extractedResume - parsed name, skills, experience, education, certifications
  • extractedJobDescription - parsed job title, required skills, experience level, responsibilities

✓ Both kept in memory until analysis is triggered.

🔍Phase 2: User Initiates Analysis

User Action: Clicks "🔍 Analyze & Match" button

System Actions:
  • Calls runAnalysis() method
  • Sends resumeText and jobDescription to backend
  • Backend service receives both pieces of content
  • Loading message: "Analyzing resume against job description..."

⚙️Phase 3: Backend Matching Algorithm

Step 1: Parse & Extract

From Resume:

  • Skills extraction
  • Years of experience
  • Education level
  • Certifications
  • Previous roles

From Job Description:

  • Required skills
  • Nice-to-have skills
  • Experience required
  • Responsibilities
  • Role level

Step 2: Skill Matching (70% Weight)

For each skill in job description:

Angular Required: Intermediate | Candidate: Advanced 95% ✅ Exceeds
TypeScript Required: Intermediate | Candidate: Intermediate 85% ✅ Meets
RxJS Required: Intermediate | Candidate: Beginner 60% ⚠️ Gap
Node.js Required: Beginner | Candidate: None 0% ❌ Critical
Average Skill Score = (95 + 85 + 60 + 0) / 4 = 60%

Step 3: Experience Matching (30% Weight)

Category Required Candidate Score
Years of Experience 5 years 7 years 100% ✅
Role Relevance Senior Frontend Dev Senior Frontend Dev 100% ✅
Average Experience Score = (100 + 100) / 2 = 100%

Step 4: Calculate Overall Match

Overall Match = (Skill Score × 0.70) + (Experience Score × 0.30) Overall Match = (60% × 0.70) + (100% × 0.30) Overall Match = 42% + 30% Overall Match = 72%

Returns comprehensive Match Report including:

💾Phase 5: Data Persistence Decision

After calculating match percentage, system decides:

✅ If Match > 80%:
  • Automatically saves ALL to MongoDB
  • Stores: Resume text, job description text
  • Stores: Extracted objects, assessment ID
  • Persistent database record created
❌ If Match ≤ 80%:
  • Keeps data ONLY in memory
  • NOT saved to database
  • Temporary assessment only
  • Lost if user closes browser

🎯Phase 6: Display Results

Shows to user:
  • Circular progress - visual representation of match %
  • Status label - Excellent/Good/Fair/Low Match
  • Detailed skill breakdown - which skills align, which have gaps
  • Gap analysis - what they need to learn
  • Training recommendations - specific courses and resources
  • Next button - to generate interview questions

🔑Key Points Summary

Storage Duration Memory until > 80% threshold met, then persistent
Algorithm Weight 70% skills + 30% experience
Match Threshold > 80% required for database persistence
Data Persistence Resume text, job description, extracted objects, match %
Memory Storage Always kept in component during session
Backend Status Currently mock, ready for real analysis

📐Algorithm Formula Reference

Match Score Calculation: ───────────────────────────────────── Step 1: Calculate Individual Skill Scores score(skill) = (candidate_proficiency_level / required_proficiency_level) × 100% Step 2: Average Skill Scores skill_score = Σ(all_skill_scores) / number_of_skills Step 3: Calculate Experience Alignment experience_score = (candidate_years / required_years) × 100% (capped at 100%, then averaged with role relevance) Step 4: Final Match Percentage MATCH % = (skill_score × 0.70) + (experience_score × 0.30) Step 5: Database Decision IF MATCH % > 80% → SAVE to MongoDB ✅ ELSE → Keep in memory only 📋
